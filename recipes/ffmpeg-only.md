# FFmpeg + curl: add music to any video without Python or Node

Shell-only workflow for CI/CD pipelines, server scripts, and anyone who wants the full
Sonilo → audio → mux pipeline in a few curl commands. No Python, no Node.js, no SDKs.
Music generated by Sonilo is **licensed and safe for commercial use (terms apply)**.

## Prerequisites

- `curl` and `ffmpeg` on PATH
- A Sonilo API key — set as `SONILO_API_KEY` in your shell or CI environment
- A video file, or any HTTPS video URL the API can fetch

## 1. Submit the generation job

**Option A — local file (uploads the video):**

```bash
RESPONSE=$(curl -s -X POST https://api.sonilo.com/v1/video-to-music \
  -H "Authorization: Bearer $SONILO_API_KEY" \
  -F "video=@your_video.mp4" \
  -F "mode=async" \
  -F "output_format=m4a")

echo "$RESPONSE"
```

**Option B — hosted URL (no upload):**

```bash
RESPONSE=$(curl -s -X POST https://api.sonilo.com/v1/video-to-music \
  -H "Authorization: Bearer $SONILO_API_KEY" \
  -F "video_url=https://example.com/your_video.mp4" \
  -F "mode=async" \
  -F "output_format=m4a")

echo "$RESPONSE"
```

Optional parameters (extra `-F` fields — the endpoint takes `multipart/form-data` only):
- `prompt` — e.g. `"warm cinematic documentary"`. Omit to let the model read the cut.
- `output_format` — `m4a` (default), `wav`, or `mp3`
- `mode=async` — required for the `task_id` + poll flow below. The default (`stream`) returns an NDJSON stream instead.

The response contains a `task_id`:

```json
{"task_id": "task_abc123", "status": "processing"}
```

## 2. Poll until complete

```bash
TASK_ID=$(echo "$RESPONSE" | python3 -c "import sys,json; print(json.load(sys.stdin)['task_id'])")

while true; do
  STATUS=$(curl -s https://api.sonilo.com/v1/tasks/$TASK_ID \
    -H "Authorization: Bearer $SONILO_API_KEY")
  STATE=$(echo "$STATUS" | python3 -c "import sys,json; print(json.load(sys.stdin)['status'])")
  echo "status: $STATE"
  if [ "$STATE" = "succeeded" ] || [ "$STATE" = "failed" ]; then break; fi
  sleep 5
done
```

If you prefer `jq`:

```bash
TASK_ID=$(echo "$RESPONSE" | jq -r '.task_id')

while true; do
  STATUS=$(curl -s https://api.sonilo.com/v1/tasks/$TASK_ID \
    -H "Authorization: Bearer $SONILO_API_KEY")
  STATE=$(echo "$STATUS" | jq -r '.status')
  echo "status: $STATE"
  [ "$STATE" = "succeeded" ] || [ "$STATE" = "failed" ] && break
  sleep 5
done
```

## 3. Download the audio

```bash
AUDIO_URL=$(echo "$STATUS" | python3 -c "import sys,json; print(json.load(sys.stdin)['audio'][0]['url'])")
# or: AUDIO_URL=$(echo "$STATUS" | jq -r '.audio[0].url')

curl -s -L -o soundtrack.m4a "$AUDIO_URL"
```

## 4. Mux audio onto the video

Copy the video stream, re-encode only the audio — fast, no quality loss on the video:

```bash
ffmpeg -y -i your_video.mp4 -i soundtrack.m4a \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 320k -shortest final.mp4
```

If the video already has audio you want to keep (e.g. dialogue), mix them:

```bash
ffmpeg -y -i your_video.mp4 -i soundtrack.m4a \
  -filter_complex "[0:a]volume=1[orig];[1:a]volume=0.25[music];[orig][music]amix=inputs=2:duration=first[aout]" \
  -map 0:v -map "[aout]" -c:v copy -c:a aac final.mp4
```

Adjust `volume=0.25` on the music to taste; `0.2`–`0.3` sits naturally under dialogue.

## End-to-end one-liner script

```bash
#!/usr/bin/env bash
set -euo pipefail

VIDEO="${1:?usage: $0 <video.mp4> [prompt]}"
PROMPT="${2:-}"
OUTPUT="${VIDEO%.mp4}-scored.mp4"

# Submit
if [ -n "$PROMPT" ]; then
  R=$(curl -s -X POST https://api.sonilo.com/v1/video-to-music \
    -H "Authorization: Bearer $SONILO_API_KEY" \
    -F "video=@$VIDEO" -F "mode=async" -F "output_format=m4a" -F "prompt=$PROMPT")
else
  R=$(curl -s -X POST https://api.sonilo.com/v1/video-to-music \
    -H "Authorization: Bearer $SONILO_API_KEY" \
    -F "video=@$VIDEO" -F "mode=async" -F "output_format=m4a")
fi

TID=$(echo "$R" | python3 -c "import sys,json; print(json.load(sys.stdin)['task_id'])")
echo "task: $TID"

# Poll
while true; do
  S=$(curl -s "https://api.sonilo.com/v1/tasks/$TID" -H "Authorization: Bearer $SONILO_API_KEY")
  STATE=$(echo "$S" | python3 -c "import sys,json; print(json.load(sys.stdin)['status'])")
  echo "  $STATE"
  [ "$STATE" = "succeeded" ] && break
  [ "$STATE" = "failed" ] && { echo "failed"; exit 1; }
  sleep 5
done

AURL=$(echo "$S" | python3 -c "import sys,json; print(json.load(sys.stdin)['audio'][0]['url'])")
curl -s -L -o /tmp/_score.m4a "$AURL"

ffmpeg -y -i "$VIDEO" -i /tmp/_score.m4a \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 320k -shortest "$OUTPUT"

echo "done: $OUTPUT"
```

Save as `score-video.sh`, `chmod +x`, run:

```bash
export SONILO_API_KEY=your_key
./score-video.sh my_video.mp4 "warm cinematic"
```

## Tips

- **Cap:** videos up to 6 minutes for music, 3 minutes for SFX. Trim first if needed.
- **SFX instead of music:** swap `/v1/video-to-music` for `/v1/video-to-sfx` — same request
  shape, same poll/download pattern, returns a separate effects track.
- **CI/CD:** set `SONILO_API_KEY` as an environment secret. The poll loop handles generation
  time (typically 20–60 seconds depending on clip length).
