# HyperFrames: score the render, then put the track back in the composition

[HyperFrames](https://github.com/heygen-com/hyperframes) picks background music from text before the
render exists: a mood query against the HeyGen catalog, or a Lyria / MusicGen prompt when there is no
HeyGen credential. This recipe adds a post-render pass instead: render the composition, hand the MP4 to
Sonilo, get back an original track composed from that render (length matched automatically), and place
it in the composition as a normal `<audio>` clip for the final render. Music generated by Sonilo is
**licensed and safe for commercial use (terms apply)**.

Nothing in HyperFrames changes. The loop is: draft render → Sonilo → final render.

## Prerequisites

- A HyperFrames project that renders (`npx hyperframes render --quality draft`)
- `curl` and `ffmpeg` on PATH
- A Sonilo API key in `SONILO_API_KEY`
- A composition that fits Sonilo's music cap (up to 6 minutes)

## 1. Turn off the built-in bgm route

If the project's media workflow writes an `audio_request.json`, set the bgm mode to `none` so the
audio engine leaves music out and only produces voice and SFX:

```jsonc
{
  "lines": [ /* your voiceover lines as before */ ],
  "bgm": { "mode": "none" }
}
```

If you never used the audio engine, skip this step. Just make sure no `<audio>` element in the
composition is already playing a music bed.

## 2. Draft render

A draft render is enough for Sonilo. Timing, cuts, and motion are what the model reads; resolution
does not matter.

```bash
npx hyperframes render --quality draft --output out/draft.mp4
```

## 3. Generate the track from the render

```bash
RESPONSE=$(curl -s -X POST https://api.sonilo.com/v1/video-to-music \
  -H "Authorization: Bearer $SONILO_API_KEY" \
  -F "video=@out/draft.mp4" \
  -F "mode=async" \
  -F "output_format=m4a")
TASK_ID=$(echo "$RESPONSE" | jq -r '.task_id')

while true; do
  STATUS=$(curl -s "https://api.sonilo.com/v1/tasks/$TASK_ID" \
    -H "Authorization: Bearer $SONILO_API_KEY")
  STATE=$(echo "$STATUS" | jq -r '.status')
  echo "status: $STATE"
  [ "$STATE" = "succeeded" ] || [ "$STATE" = "failed" ] && break
  sleep 5
done

mkdir -p assets/bgm
curl -s -L -o assets/bgm/sonilo.m4a "$(echo "$STATUS" | jq -r '.audio[0].url')"
```

Add `-F "prompt=warm, cinematic, building to a swell"` to steer the style. Leave it out and the model
scores what it sees in the cut, which is usually the better default. The full parameter list and the
Python version live in the [FFmpeg-only recipe](./ffmpeg-only.md).

## 4. Place the track and render for real

Add one `<audio>` clip to the composition. Every `<audio>` needs an `id`, or the mixer skips it and
the render is silent. `data-duration` is the composition length in seconds; `data-track-index` is only
the Studio display lane.

```html
<audio
  id="bgm"
  src="assets/bgm/sonilo.m4a"
  data-start="0"
  data-duration="42"
  data-track-index="10"
  data-volume="0.2"
></audio>
```

`0.2` sits under a voiceover; use `0.9` for a piece with no narration. For a fade-out, animate `volume`
on the timeline instead of changing `data-volume`:

```js
tl.to("#bgm", { volume: 0, duration: 1 }, "outro");
```

Then:

```bash
npx hyperframes render --quality high --output out/final.mp4
```

Re-render the picture without re-scoring as often as you like. Regenerate the track only when the cut
changes, since the music is composed to the edit.

## Alternative: mux without a second render

When the final render already exists and you just want the audio on it:

```bash
ffmpeg -y -i out/final.mp4 -i assets/bgm/sonilo.m4a \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 320k -shortest out/final-scored.mp4
```

If the render carries a voiceover, mix instead of replace:

```bash
ffmpeg -y -i out/final.mp4 -i assets/bgm/sonilo.m4a \
  -filter_complex "[0:a]volume=1[vo];[1:a]volume=0.25[music];[vo][music]amix=inputs=2:duration=first[aout]" \
  -map 0:v -map "[aout]" -c:v copy -c:a aac out/final-scored.mp4
```

Or ask Sonilo to duck for you: add `-F "ducking=true"` in step 3 and download `ducked[0].url` instead
of `audio[0].url` (the clean track stays in `audio[0]`). See [Ducking & speech](./ducking.md).

## Tips

- **Agent sessions:** HyperFrames is agent-native. The [Sonilo MCP server](https://github.com/sonilo-ai/sonilo-mcp)
  exposes the same call as a `video_to_music` tool, so an agent can run this loop without curl.
- **Sound effects too:** `POST /v1/video-to-sfx` on the same draft render returns royalty-free effects
  timed to the picture. Place them the same way. Cap: 3 minutes.
- **Batch renders:** score each `--batch` output separately. The music is composed to that cut.
